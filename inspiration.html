03 / funding policy

WHO PAYS WHEN AI runs?

One project can be developer-funded, user-funded, or hybrid. The funding policy changes the transaction, not the developer's integration.

01 / developer

You fund the experience.

Your app pays the provider. SpendGuard still meters usage and enforces a hard exposure ceiling.

USER REQUEST↓DEVELOPER WALLET↓AI PROVIDER
02 / user

The user funds their usage.

Credits or pay-as-you-go balance become the source of truth for the request.

USER WALLET↓SPENDGUARD↓AI PROVIDER
03 / hybrid

Subsidize the first $1.

Use developer funds first, then fall back to user balance when the subsidy is exhausted.

DEVELOPER↓$1 SUBSIDY↓USER BALANCE
